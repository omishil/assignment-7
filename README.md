# বাজার দর (BazarDor)

বাজার দর is a responsive web application that helps users quickly view current prices for essential everyday products in one place.

## Technologies used

- Next.js
- React
- Tailwind CSS
- Better Auth
- JavaScript
- REST API

## Key features

1. **Product price overview** — Browse essential products and view their current prices and units.
2. **Price movement indicators** — See whether prices increased, decreased, or stayed unchanged.
3. **Responsive design** — Works across mobile, tablet, and desktop screens.
4. **Multiple authentication methods** — Email/password, Google, and GitHub sign-in.
5. **Profile and account controls** — View profile details and securely sign out.
